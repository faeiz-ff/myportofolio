Simpl: Indonesian Mini Programming Language (Oct 2025 - Jan 2026)

GitHub Website

Simpl merupakan bahasa pemrograman yang saya buat untuk lebih mudah menerjemahkan konsep pemrograman ke bahasa indonesia. Ini cobaan pertama saya dalam membuat bahasa yang relatif bisa digunakan untuk mengekspresikan program apapun secara umum. Saya melihat Simpl sebagai pseudocode bahasa indonesia yang bisa dijalankan.

Proyek ini mengajari saya banyak hal, utamanya terkait teknik kompilator. Tapi saya sendiri jadi lebih tau tentang bahasa JavaScript yang saya gunakan untuk membangun bahasa ini — benar sekali, bahasa interpreted dalam bahasa interpreted. Bisa dibilang proyek ini membuat saya fasih berbahasa JavaScript dan hal-hal Object Oriented. Namun, saya sangat menyesal tidak membangun proyek ini dalam TypeScript, karena saya banyak sekali mengalami Type Error dengan banyaknya polymorphism yang terjadi. Saya jadi belajar untuk mencintai bahasa strongly-typed.

Saya juga membuat website Simpl memakai TypeScript dengan stack: React + Tailwind untuk frontend, React-Router untuk routing, Vite untuk build tool. Hal tersebut juga mengajari saya banyak tentang mendesain website, ekosistem JavaScript yang sangat... err... begitulah. It's still fun though.

luv Programming Language (May 2026 - still in development)

GitHub

Luv adalah bahasa pemrograman yang simpel dengan tampilan yang 'halus' dan sistem typing yang kuat. Sintaksisnya terinspirasi dari Go, Rust, Zig, dan Python. Luv menggabungkan Object-Prototype runtime model dari JavaScript dan sistem tipe statis dari TypeScript dalam satu bahasa. Kenapa? Karena itu model bahasa menarik yang relatif simpel untuk diimplementasi.

Lalu, kenapa bahasa baru lagi? — yang kemungkinan besar orang tidak akan pakai juga — Karena tujuan utama saya bukan hanya untuk membangun bahasa, tetapi juga untuk mempelajari sistem low-level. Proyek ini amat sangat membantu saya lebih memahami konsep sistem komputer: manajemen memori, alokator, lifetime, ownership, dan lain-lain; karena proyek ini menggunakan bahasa yang compiled: Bahasa pemrograman Zig.

Awalnya saya memakai bahasa C, dan iya, saya menjadi tahu betapa simpel dan bebasnya bahasa C, saya menjadi mengerti bahasa C. Tetapi saya harus akui, saya terganggu dengan intrikasi mekanisme bahasa C yang sangat samar; penuh hal tersembunyi. Saya merasa kesulitan untuk memahami konsep sistem yang sebenarnya. Lalu saya menemukan bahasa Zig.

Saya jatuh cinta saat pertama kali memakai Zig. Bahasanya simpel, eksplisit, dan tidak mempunyai intrikasi samar seperti bahasa C. Bahasanya sangat modern, ergonomis, tetap manual seperti C, bahkan lebih manual dalam beberapa kasus. Saya merasa lebih mengerti C setelah bermain-main dengan Zig.

Karena alasan pembelajaran tersebut, saya merasa Rust kurang cocok untuk dipilih di proyek ini. Rust lebih tergolong high-level — ini pujian untuk bahasa yang dikompilasi — daripada Zig atau C. Mungkin saya akan kurang mengerti hal yang sebenarnya terjadi di balik abstraksi yang Rust tawarkan. Still, I love all languages though.
